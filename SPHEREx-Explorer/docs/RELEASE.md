# Release 2.2.0 — Focused Comparison

A targeted UX refinement of the 2.1.0 observation-fields release. Scientific measurements, prepared images, source hashes, processing pipelines and approved space artwork are unchanged.

- Five prominent target options open a prepared field or archive availability. M101 remains the default real-data example.
- A/B images lead the comparison page. Playback, blink, zoom, brightness and reset are immediately accessible; additional controls and scientific detail are expandable.
- The desktop app uses 85% layout scale; smaller screens retain full-size controls. Homepage copy has more breathing room.
- New map entries show the whole globe. Explicit focus and profile-return camera restoration remain available.
- Infrared charts zoom within their marked corners, with correctly updated linear/logarithmic axes and unchanged data. Every selected comparison is highlighted in catalog overview.
- Redundant role placeholders and internal submission reminders are removed from the interface. Team-description documents are unchanged. Scientific provenance and asset/software acknowledgements remain available.

The Complete Source and Owner Netlify packages contain the full modeled catalog and all existing tools. Public Source and Public Netlify contain the real-observation edition, excluding workbook-derived records with undocumented redistribution terms.

`BUILD_SOURCE.json`, `SOURCE_FILES.sha256` and `build-info.json` identify the exact source and compiled assets. `TEST_REPORT.md` describes validation scope and remaining environment limits. This release is packaged and saved without replacing production.
